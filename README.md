# 🎮 GameStore — Цифровой магазин игр на Django

**Автор:** Максим Юрин 

Дипломный проект: веб-приложение для продажи цифровых игр с регистрацией пользователей, корзиной, оформлением заказов и демонстрационной платёжной системой.

## 📋 Функционал

- Регистрация и аутентификация пользователей (стандартная Django auth)
- Каталог игр с обложками и описанием
- Корзина на основе сессий
- Оформление заказа с сохранением в БД
- Имитация платёжной системы (готова к замене на ЮKassa/Stripe)
- Админ-панель для управления играми и заказами
- Минималистичный адаптивный интерфейс на чистом HTML/CSS

## 🛠 Технологии

- Python 3.10+
- Django 5.x
- SQLite (для разработки)
- Pillow (для изображений)
- python-decouple (для переменных окружения)
